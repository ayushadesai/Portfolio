# Ayush Desai — Portfolio

Personal portfolio site built with React, TypeScript, Vite, and Tailwind CSS. Deployed on Vercel.

**Live:** https://ayushadesai-portfolio.vercel.app

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router v6
- Fonts: Geist, Inter, Inconsolata (Google Fonts)

## Pages

- `/` — About: bio, info card, experience cards, skills strip, education
- `/projects` — Featured projects with build breakdowns
- `/resume` — Full résumé with experience, education, skills, and projects

## Development

```bash
npm install
npm run dev
```

## Deployment

Vercel. `vercel.json` includes a catch-all rewrite to `index.html` for SPA routing.
